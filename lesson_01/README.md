## Что делаем на паре

- [ ] Поднять стенд: `cd stend && docker compose up -d`, дождаться статуса `healthy`
- [ ] Подключиться из Compass строкой `mongodb://localhost:27017`
- [ ] Создать базу `hh` и коллекцию `resumes`
- [ ] Вставить **своё** резюме руками: не меньше пяти полей, из них один массив
- [ ] Загрузить `stend/seed/resumes.json` и проверить счётчик: `1 – 9 of 9` — восемь загруженных плюс ваш
- [ ] Собрать пять запросов и записать числа в `queries.md`
- [ ] Сломать один запрос намеренно и описать, чем ошибка разбора отличается от пустого результата

## Пять запросов

Числа в таблице — по восьми документам из `stend/seed/resumes.json`.
Ваш собственный документ в них не входит: он может добавить к любому
из этих чисел единицу, и это нормально.

| Что ищем | Фильтр | Находится в восьми загруженных |
|---|---|---|
| точное совпадение строки | `{ city: "Ярославль" }` | 4 |
| поле внутри объекта | `{ "education.level": "СПО" }` | 4 |
| элемент массива | `{ skills: "MongoDB" }` | 2 |
| сравнение чисел | `{ salary: { $gt: 100000 } }` | 4 |
| наличие поля | `{ portfolio: { $exists: true } }` | 2 |

Если ваши числа меньше — импорт не дошёл до конца. Если заметно больше —
импорт прошёл дважды: очистите коллекцию (`docker compose down -v`,
затем `up -d`) и повторите.

Сортировка, проекция и ограничение количества прячутся за кнопкой **Options**
рядом со строкой запроса.
