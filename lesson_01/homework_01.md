# Домашнее задание № 1 · hw-01

Срок — до начала занятия 2.

## 1. Своя коллекция

Возьмите предметную область из своего проекта: карточку заказа, сервисный
тикет, объявление, запись на приём. Спроектируйте документ и положите
в новую коллекцию **пять** таких документов.

Минимум у двух документов форма должна отличаться: лишнее поле или
отсутствующее. Это не небрежность, а то, ради чего документная база и берётся.

В документе должны встретиться:

- вложенный объект — поле, у которого значение само является документом;
- массив — список значений или объектов;
- число и строка в явно разных полях (пригодится в запросе со сравнением).

Готовый набор сохраните в `lesson_01/seed.json` так, чтобы он загружался
через **ADD DATA → Import JSON or CSV file** без правок руками.

## 2. Шесть запросов

К своей коллекции соберите пять видов фильтров:

1. точное совпадение строки;
2. поле внутри вложенного объекта — через точку;
3. элемент массива;
4. оператор сравнения (`$gt`, `$lt`, `$gte`, `$lte`);
5. наличие поля — `$exists`.

Шестым запишите **намеренно неверный** фильтр и объясните, что произошло:
ошибка разбора (красная рамка, кнопка Find недоступна, запрос на сервер
не ушёл) или пустой результат (счётчик `0 – 0 of 0`, фильтр разобрался,
но ничего не нашёл). Разница между этими двумя случаями и есть смысл задания.

Всё записывается в `lesson_01/queries.md` по бланку, который там уже лежит.

## 3. Абзац о цене

В конце `queries.md` — несколько предложений своими словами:

- что в вашем документе продублировано;
- во что обойдётся изменение этого значения, если документов станет двести;
- почему вы всё-таки решили продублировать, а не выносить в отдельную коллекцию.

Без формулировок из документации и без общих слов: на своих данных
и со своим решением.

## Как сдать

```bash
git switch -c hw-01
git add lesson_01
git commit -m "hw-01: коллекция <ваша область>, шесть запросов, разбор дубликата"
git push -u origin hw-01
```

Дальше на GitHub — **Pull Request** в свою `main`, в описании: какая
предметная область, чем отличаются формы документов, что оказалось
неожиданным. Merge делаете сами после проверки.

## Как проверяется

Числа в `queries.md` сверяются с вашей коллекцией на приёмке. Скриншот
без работающего стенда не принимается: со следующего занятия мы дописываем
в эту же базу.

ИИ можно просить причесать формулировки и оформить `.md` — я сам так делаю
всегда, поэтому и вам запрещать не буду. Но запросы должны быть выполнены
на вашем стенде, и на приёмке вы объясняете любой из шести.
